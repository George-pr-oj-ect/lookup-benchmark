# IRONFIT 💪

A gym equipment e-commerce web app built with vanilla HTML, CSS, and JavaScript. Includes login/register, a product store, cart, checkout, and order confirmation, all handled client-side with localStorage.

## Pages
- **Login/Register** — user authentication using localStorage
- **Store** — browse gym equipment, add items to cart
- **Cart** — view items, update quantities, remove items, see running total
- **Checkout** — enter shipping details with form validation
- **Confirmation** — order summary and estimated delivery

## Features
- User authentication (sign up / login) with localStorage, no backend needed
- Persistent cart across pages and sessions
- Form validation on checkout
- Dark theme UI with glassmorphism cards and a warm orange accent
- Fully responsive across mobile, tablet, and desktop

## Tech Stack
- HTML5
- CSS3 (Flexbox, backdrop blur, custom animations, responsive media queries)
- JavaScript (DOM manipulation, localStorage, form validation)

## What I Learned
Building IRONFIT was my first full multi-page project without a framework. It gave me hands-on experience passing data between pages using localStorage (since there's no backend), structuring a consistent design system across multiple HTML files, and validating user input before allowing checkout.
